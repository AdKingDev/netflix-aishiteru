# netflix-aishiteru  

![preview](assets/images/01.jpg)

Netflix 愛してる é uma página web inspirada na interface da Netflix, desenvolvida como um presente para uma pessoa especial.  
O projeto combina **HTML**, **CSS** e **JavaScript**, com foco em **Mobile First** e espaço para melhorias futuras.  
Também foi utilizado o **Swiper.js** para criar um **carrossel animado com transição contínua**.  

---

## Acesse o site  

🔗 [Clique aqui para ver o projeto online](https://netflix-aishiteru.vercel.app/)  

---

## Tecnologias utilizadas  

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **Swiper.js**
